# ClaudeHero Website

Landing page ธีมขาวดำพรีเมียมสำหรับ ClaudeHero ผู้ให้บริการโซลูชัน AI สร้างด้วย HTML, CSS และ JavaScript ล้วน ไม่มี framework หรือ build step

## วิธีเปิดดู
ดับเบิลคลิก `index.html` หรือ deploy โฟลเดอร์นี้ขึ้น static hosting ใดก็ได้ เช่น GitHub Pages, Netlify หรือ Vercel

## โครงสร้าง
```
index.html      หน้าเว็บ (ทุก section)
css/style.css   สไตล์และ responsive
js/main.js      แอนิเมชันและส่วนที่โต้ตอบได้
```

## ส่วนในหน้า
Hero (particle background) · แถบรายชื่อลูกค้า · บริการ 6 อย่าง · สถิติ · ขั้นตอนการทำงาน · แพ็กเกจราคา (รายเดือน/รายปี) · รีวิว · FAQ · ฟอร์มติดต่อ

## หมายเหตุ
- ฟอร์มติดต่อยังไม่ได้เชื่อมกับระบบหลังบ้าน ตอนนี้แค่แสดงข้อความว่าส่งสำเร็จ
- รายชื่อลูกค้า รีวิว สถิติ ราคา และข้อมูลติดต่อเป็นข้อมูลตัวอย่าง
